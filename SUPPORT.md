# Support

Start with the [README](README.md), the [repository documentation](docs/) and
[existing issues](https://github.com/php-fast-forward/changelog/issues).
Development is maintained on `main`; there are currently no published releases.

## Choosing a channel

- Usage questions: open an [issue](https://github.com/php-fast-forward/changelog/issues/new)
  describing your goal and the behavior you need help understanding.
- Reproducible defects: use the
  [bug report form](https://github.com/php-fast-forward/changelog/issues/new?template=bug-report.yml).
- Proposed improvements: use the
  [feature request form](https://github.com/php-fast-forward/changelog/issues/new?template=feature-request.yml).
- Suspected vulnerabilities: follow the private reporting instructions in
  [SECURITY.md](SECURITY.md).
- Community conduct concerns: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Useful report details

Include the package version or commit, PHP and Composer versions, operating
system, the exact command or API call, and the expected and observed behavior.
For parsing or rendering problems, include a small Markdown or fragment example
that reproduces the issue. State the locale or custom template when relevant.
Check for related open and closed issues before filing a new report.

Keep examples minimal and remove credentials, tokens, personal data and private
repository contents. Contribution and local validation guidance is in
[CONTRIBUTING.md](CONTRIBUTING.md).
